# Developer demonstration

[Watch on YouTube](https://youtu.be/8uiZaVtBBH4) · [Read the project page](https://shiruifu.online/projects/carrot-duck/)

The video presents the conversational interface, management dashboard and Live2D performance system through a situated dialogue. It illustrates how an earlier encounter can inform a later response and how speech is coordinated with character expression. The sequence is prepared for demonstration; it is not a user study or evidence that the current autonomous mode generated the recorded performance.

The later autonomous mode uses account-scoped retrieval and generated dialogue. Its inspect panel exposes candidate memories, model-declared citations and a performance plan. With a configured character, the browser reports whether playback started, completed, failed or was cancelled. These reports describe execution, not the user's interpretation of the exchange.

The public repository provides a smaller local interface for running this path. The video remains the reference for the deployed application's broader interface. A reproduction with another licensed model will differ visually from the recording.
